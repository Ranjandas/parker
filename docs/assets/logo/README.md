# Parker logo

Parker is named after the Parker Solar Probe, the fastest human-made object. The logo is a "P" whose bowl is the sun, with speed lines trailing off the stem: speed, and a nod to the probe that inspired the name.

Chosen concept: **B. Monogram** (2026-11-19). 

## Files

| File | Use |
|---|---|
| `parker-logo.svg` | Mark + wordmark lockup. Switches ink colour with the viewer's light/dark setting. |
| `parker-logo-light.svg`, `parker-logo-dark.svg` | Fixed versions for light / dark backgrounds (e.g. GitHub `<picture>`). |
| `parker-mark*.svg` | Mark only, same three variants. |
| `parker-wordmark*.svg` | Wordmark only (drawn as paths, no font needed). |
| `favicon.svg` | Simplified, chunkier mark for 16-32 px; adapts to light/dark. |
| `favicon.ico` | 16/32/48 px, app-icon style (navy tile) so it reads on any tab colour. |
| `parker-app-icon.svg`, `parker-icon-{32,180,192,512}.png` | Navy rounded tile for avatars, apple-touch-icon, social/OG. |

Colours: ink `#0F1B2D` (light) / `#F4F1EA` (dark); sun gradient `#FFC94A` → `#FF7A1A` → `#FF4D2E`.
